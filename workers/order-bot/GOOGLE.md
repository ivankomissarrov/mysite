# Заявки через Google Apps Script

Чтобы клик по MAX присылал только строку «Вам скоро напишут в MAX», а не заказ с ценами, замените код в уже созданном проекте:

1. Откройте [свои проекты](https://script.google.com/home).
2. Откройте `order-bot` (или тот проект, который уже развёрнут).
3. Полностью замените `Code.gs` файлом [`google-apps-script.gs`](google-apps-script.gs).
4. Сохраните.
5. **Развернуть → Управлять развёртываниями → карандаш → Новая версия → Развернуть**. URL `.../exec` должен остаться тем же.

Ниже — полная первая установка, если проекта ещё нет.

---

Тот же смысл, что у Яндекс Functions: браузер клиента шлёт заявку на ваш скрипт, скрипт пишет боту в Telegram. Денег и залога нет. Из России `script.google.com` обычно открывается, в отличие от Cloudflare.

Нужен обычный Google-аккаунт. Токен бота в git не кладётся.

## 1. Проект

1. Войдите в [Google](https://accounts.google.com/).
2. Откройте [script.google.com/home](https://script.google.com/home).
3. **Новый проект**. Документация: [веб-приложения Apps Script](https://developers.google.com/apps-script/guides/web).

## 2. Код

1. Удалите содержимое `Code.gs`.
2. Вставьте файл [`google-apps-script.gs`](google-apps-script.gs).
3. Сохраните (Ctrl+S).

## 3. Секреты бота

1. Слева шестерёнка **Настройки проекта**.
2. Блок **Свойства скрипта** → **Добавить свойство скрипта**.
3. Два свойства:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
   - `CHAT_ID` — ваш числовой id (уже есть после `/start` боту).
4. Сохраните.

Про свойства: [Properties Service](https://developers.google.com/apps-script/guides/properties).

## 4. Разрешить доступ в интернет

Один раз из редактора:

1. Сверху выберите функцию `doGet`.
2. Нажмите **Выполнить**.
3. Разрешите доступ своему аккаунту (окно Google).

Так скрипт получит право вызывать Telegram.

## 5. Опубликовать как веб-приложение

1. Справа сверху **Развернуть** → **Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. Описание: `order-bot`.
4. **Запускать от имени:** меня.
5. **У кого есть доступ:** все.

   Это обязательно: иначе форма с сайта не достучится.

6. **Развернуть**. Скопируйте URL вида  
   `https://script.google.com/macros/s/..../exec`

Если правите код позже: **Развернуть** → **Управлять развёртываниями** → карандаш → **Новая версия**. Это нужно и после добавления уведомления про MAX.

## 6. Подключить к сайту

В `src/data/order-catalog.json` (или в `tools/order-editor.html`) в поле `endpoint` вставьте этот URL. Закоммитьте и задеплойте сайт.

Пока `endpoint` пустой, форма не пишет боту сама.

## Проверка

Откройте `/order/`, укажите телефон, отправьте заявку. Сообщение должно прийти в [@IKomissarovBot](https://t.me/IKomissarovBot). Ошибки смотрите в Apps Script: **Журнал выполнения**.
