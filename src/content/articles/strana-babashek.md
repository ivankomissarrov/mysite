Самый большой проект моего авторства по объёму продаж — напольная игра «Страна Бабашек»: набор мини-игр для детских садов на основе деревянного конструктора.

Несколько ночей думал, как сделать драйвовую игру для детей, которые ещё не умеют читать, так чтобы в неё можно было играть вдесятером. Решением стал визуальный язык «чертежей».

Для сюжета появился антагонист Шах Бабах. По открытой статистике «Русского медвежонка» выручка составила больше 3,5 млн рублей.
