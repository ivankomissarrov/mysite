# Личный сайт Ивана Комиссарова

Персональный сайт с постами. Стиль взят из макета Figma «Презентации фиолетовые»: тёмный фон, фиолетовое свечение, стеклянные карточки и крупная типографика как на слайдах.

## Как запустить на localhost

Нужен Node.js **18.20+**, **20** или **22**. Проверка: `node -v`.

```bash
npm install
npm start
```

Сервер должен написать `http://localhost:4321/` или `http://0.0.0.0:4321/`. Откройте:

**http://localhost:4321**

Если не открывается — **http://127.0.0.1:4321**. В Cursor Cloud превью ходит на этот же порт; сервер слушает `0.0.0.0`, иначе будет 502.

Остановка сервера: `Ctrl+C`.

## Сборка

```bash
npm run build
npm run preview
```

## Как написать пост

1. Создайте файл в `src/content/articles/`, например `novaya-zametka.md`.
2. Добавьте шапку:

```md
---
title: 'Заголовок'
description: 'Короткое описание для поиска и соцсетей.'
pubDate: 2026-08-14
tags: ['тема']
---
```

3. Ниже напишите текст в Markdown. Картинки можно вставить как обычные ссылки — при `npm start` или `npm run build` скрипт `scripts/local-assets.mjs` скачает их в `public/images/articles/`, сделает лёгкие превью и подменит адреса на локальные.
4. Пост появится по адресу `/posts/novaya-zametka/`, на главной и в RSS. На главной сначала видны свежие карточки, остальные открываются стрелкой вниз.

Шрифты Unbounded и Manrope лежат в `public/fonts/` и не запрашиваются у Google. Если папку удалить, тот же скрипт скачает их снова.

Аватарка: положите исходник в `public/images/avatar.jpg`. При старте скрипт вырежет крупный кадр головы и сделает `public/images/avatar.webp` для главной и шапки.

## Перед публикацией

В `src/data/site.ts` и `astro.config.mjs` замените адрес сайта на свой домен. Имя, описание и ссылки правятся в `src/data/site.ts`.
