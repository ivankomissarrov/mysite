# Личный сайт Ивана Комиссарова

Персональный сайт со статьями. Стиль взят из макета Figma «Презентации фиолетовые»: тёмный фон, фиолетовое свечение, стеклянные карточки и крупная типографика как на слайдах.

## Как запустить на localhost

Нужен Node.js **18.20+**, **20** или **22**. Проверка: `node -v`.

```bash
npm install
npm start
```

Сервер должен написать `http://localhost:4321/` или `http://0.0.0.0:4321/`. Откройте:

**http://localhost:4321**

Если не открывается — **http://127.0.0.1:4321**. В Cursor Cloud превью ходит на этот же порт; сервер слушает `0.0.0.0`, иначе будет 502.

Остановка сервера: `Ctrl+C`.

## Сборка

```bash
npm run build
npm run preview
```

## Как написать статью

1. Создайте файл в `src/content/articles/`, например `novaya-zametka.md`.
2. Добавьте шапку:

```md
---
title: 'Заголовок'
description: 'Короткое описание для поиска и соцсетей.'
pubDate: 2026-08-14
tags: ['тема']
---
```

3. Ниже напишите текст в Markdown.
4. Статья появится по адресу `/articles/novaya-zametka/`, на главной и в RSS.

## Перед публикацией

В `src/data/site.ts` и `astro.config.mjs` замените адрес сайта на свой домен. Имя, описание и ссылки правятся в `src/data/site.ts`.
